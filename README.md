# Цветочки — интернет-магазин цветов

Учебный интернет-магазин букетов. В нём есть каталог с фильтрами и поиском, окно товара, избранное, корзина и оформление заказа. Сайт работает целиком в браузере, без сервера и базы данных.

**Стек:** React 19 · Vite 8 · Tailwind CSS 3 · иконки lucide-react.

## Быстрый старт

**Что нужно:** [Node.js](https://nodejs.org/) версии 20.19 или новее. Проверить версию можно командой `node -v`.

```bash
# 1. перейти в папку проекта
cd СайтЦветочки

# 2. установить зависимости (один раз, около минуты)
npm install

# 3. запустить сайт
npm run dev
```

Откройте в браузере **http://localhost:5173**.

Пока команда `npm run dev` работает, любое изменение в коде сразу появляется на странице, перезагружать её не нужно. Остановить сервер: `Ctrl + C` в терминале.

## Публикация в интернете

После `npm run build` в папке `dist/` лежит обычный статический сайт: один `index.html` плюс файлы стилей, скриптов и картинок. Его можно выложить на любой хостинг статики.

**Vercel (проще всего):**
1. Загрузите проект на GitHub.
2. На [vercel.com](https://vercel.com) нажмите **Add New → Project** и выберите репозиторий.
3. Vercel сам определит Vite: Build Command `npm run build`, Output Directory `dist`. Нажмите **Deploy**.

**Netlify:** то же самое, или просто перетащите папку `dist/` на [app.netlify.com/drop](https://app.netlify.com/drop).

Адреса страниц устроены через `#` (`/#catalog`), поэтому никакие настройки перенаправлений на хостинге не нужны.

## Что есть на сайте

| Раздел | Адрес | Что умеет |
|---|---|---|
| **Главная** | `#home` | Первый экран с фото, категории-арки, лента хитов, баннер «букет под событие», шаги «Как мы работаем», отзывы |
| **Каталог** | `#catalog` | Фильтры (категория, цена, «только со скидкой»), сортировка, вид сеткой или списком, кнопка «Показать ещё» |
| **Окно товара** | поверх любой страницы | Фото, описание, выбор размера, количество, «В корзину», избранное, состав |
| **Избранное** | `#favorites` | Сохранённые товары, «Всё в корзину», очистка |
| **Корзина** | `#cart` | Список товаров, изменение количества, форма доставки, итог, оформление |

**Шапка:** логотип по центру. Справа значки поиска, избранного и корзины со счётчиками. На компьютере под шапкой ссылки на категории, на телефоне вместо них бургер-меню слева.

**Поиск:** лупа в шапке открывает строку. Как только начинаешь печатать, сайт переходит в каталог и ищет по названию, описанию и составу букета.

**Телефон:** фильтры каталога выезжают шторкой снизу, окно товара тоже открывается снизу. Закрыть любое окно можно крестиком, тапом по затемнённому фону или клавишей `Esc`.

**Сохранение:** корзина и избранное хранятся в браузере и не теряются после перезагрузки страницы.

**Заказ:**
1. Выберите доставку курьером или самовывоз.
2. Заполните имя, телефон и адрес.
3. Укажите дату, время и, если нужно, текст открытки.

Если поле заполнено неверно, под ним появится подсказка. После оформления показывается номер заказа, а корзина очищается.

**Доставка:** 390 ₽, бесплатно от 5 000 ₽. Самовывоз всегда бесплатный.

      ├─ Footer.jsx        подвал
      ├─ HomePage.jsx      главная
      ├─ Catalog/
      │  ├─ Catalog.jsx    каталог с фильтрами
      │  └─ ProductCard.jsx карточка товара и сетка карточек
      ├─ ProductModal.jsx  окно товара
      ├─ FavoritesPage.jsx избранное
      ├─ CartPage.jsx      корзина и форма заказа
      ├─ Overlay.jsx       общее всплывающее окно (меню, фильтры, товар)

### Как части связаны

```
main.jsx
 └─ App.jsx
     ├─ CartProvider       ← корзина доступна всем ниже
     │   └─ FavoritesProvider  ← избранное доступно всем ниже
     │       ├─ Header
     │       ├─ HomePage | Catalog | FavoritesPage | CartPage   (одна из них)
     │       ├─ Footer
     │       ├─ ProductModal   (если открыт товар)
     │       └─ Toast
```

`App.jsx` знает только три вещи: какая страница открыта, какая категория выбрана и какой товар показать в окне. Корзину и избранное любой компонент берёт сам через `useCart()` и `useFavorites()`, передавать их через пропсы не нужно.

## Как это работает внутри

### Переключение страниц

Страница определяется по части адреса после `#`: `#catalog`, `#cart`, `#favorites`. В `App.jsx` есть функция `navigate(page)`, она меняет `location.hash`. Браузер сообщает об этом событием `hashchange`, и `App` показывает нужную страницу. Благодаря этому работают кнопки «Назад» и «Вперёд» в браузере, а ссылку на каталог можно скопировать.

Окно товара — это просто `productId` в состоянии `App`. Если он не пустой, поверх страницы рисуется `ProductModal`.

### Товары

Все товары лежат в одном массиве в `src/data/products.js`:

```js
{ id: 'r-101',                 // уникальный код, по нему ищется фото
  category: 'roses',           // id категории
  title: '101 розовая роза',
  oldPrice: 9990,              // необязательно — старая цена, товар попадёт в «со скидкой»
  rating: 5.0, reviews: 143,   // для сортировки «по рейтингу» и «популярные»
  badge: 'Хит',                // необязательно — плашка на фото
  description: '…',
  composition: ['Роза', '…'],  // состав, по нему тоже работает поиск
  sizes: [['51 роза', 8990], ['101 роза', 15990]] }  // размер и цена
```

Цена «от …» на карточке считается автоматически из первого размера. Если размеров нет, укажите просто `price: 2990`.

Количество товаров в категориях тоже считается само, руками его писать не нужно.

### Фото

`Media.jsx` с помощью `import.meta.glob` при сборке находит все картинки в `src/assets/products/` и сопоставляет их с товарами по имени файла: `r-101.jpg` → товар с `id: 'r-101'`. Если фото нет, показывается светлый фон с иконкой цветка. Логотип ищется так же, файл `src/assets/logo.png` (или `.svg`).

### Корзина

`CartContext.jsx` хранит в браузере только короткие записи:

```js
{ key: 'r-101:51 роза', productId: 'r-101', size: '51 роза', quantity: 2 }
```

Название и цена каждый раз берутся из `products.js`. Поэтому если поменять цену в каталоге, она сразу поменяется и у тех, у кого товар уже лежит в корзине.

Из корзины доступно:

| Функция | Что делает |
|---|---|
| `addToCart(товар, количество, размер)` | Добавить товар |
| `updateQuantity(key, ±1)` | Изменить количество (при нуле позиция удаляется) |
| `removeFromCart(key)` | Удалить позицию |
| `productQty(id)` | Сколько штук товара в корзине (для счётчика на карточке) |
| `subtotal`, `deliveryCost`, `freeDeliveryLeft` | Итоги корзины |
| `createOrder(данные, доставка)` | Оформить заказ: создаёт номер, сохраняет заказ в браузере, чистит корзину |
| `showToast(текст)` | Показать уведомление внизу экрана |

### Что хранится в браузере

| Ключ в `localStorage` | Что там |
|---|---|
| `cvetochki_cart` | корзина |
| `cvetochki_favorites` | id избранных товаров |
| `cvetochki_orders` | оформленные заказы |

Посмотреть или очистить: инструменты разработчика (F12) → **Application** → **Local Storage**.

### Каталог

`Catalog.jsx` держит фильтры в обычном состоянии: сортировку, цену, «только со скидкой», вид и сколько товаров показано. При каждом изменении список заново фильтруется и сортируется через `useMemo`. Один и тот же блок фильтров рисуется в двух местах: в левой колонке на компьютере и в шторке на телефоне.

### Окна

`Overlay.jsx` — общий компонент для мобильного меню, шторки фильтров и окна товара. Он рисует затемнённый фон, закрывает окно по `Esc` и по клику на фон и запрещает прокрутку страницы под окном. Параметр `side` задаёт, откуда окно появляется: `center`, `bottom` или `left`.

### Стили

Стили пишутся классами Tailwind прямо в JSX: `className="text-sm text-stone-500"`. Повторяющиеся наборы вынесены в `src/index.css`:

| Класс | Что это |
|---|---|
| `.page` | Контейнер по ширине сайта с отступами по бокам |
| `.btn-primary`, `.btn-outline`, `.btn-ghost` | Кнопки |
| `.input` | Поле ввода (на телефоне шрифт 16px, чтобы iPhone не увеличивал страницу) |
| `.label` | Маленькая подпись капсом |
| `.icon-btn` | Круглая кнопка-иконка |

Цвета заданы в `tailwind.config.js`:

| Цвет | Назначение |
|---|---|
| `brand-*` | Тёмная зелень, основной цвет |
| `blush-*` | Пыльная роза, акцент |
| `cream` | Фон |

Адаптация под экраны идёт от телефона к компьютеру: класс без префикса действует везде, `sm:` начиная с 640px, `md:` с 768px, `lg:` с 1024px. Например, `grid-cols-2 lg:grid-cols-4` означает 2 колонки на телефоне и 4 на компьютере.

## Как поменять под себя

**Добавить товар**
1. В `src/data/products.js` скопируйте любой объект в `RAW_PRODUCTS` и поменяйте `id`, название, цены и остальные поля.
2. Положите фото в `src/assets/products/<id>.jpg`. Лучше вертикальное, примерно 4:5.

**Убрать товар:** удалите его объект из `RAW_PRODUCTS`, а фото можно оставить или тоже удалить.

**Добавить категорию**
1. Добавьте строку в `BASE_CATEGORIES`: `{ id: 'peonies', name: 'Пионы' }`.
2. Укажите `category: 'peonies'` у нужных товаров.

Категория сама появится в шапке, фильтрах, меню, подвале и на главной.

**Поменять логотип:** положите `src/assets/logo.png` или `logo.svg`. Высота логотипа задаётся в `Media.jsx`, классом `h-9 sm:h-11`.

**Поменять цвета:** откройте `tailwind.config.js` и замените значения `brand` (основной цвет) и `blush` (акцент).

**Поменять телефон и контакты:** они записаны в `src/components/Footer.jsx` и в кнопке «Позвонить флористу» в `src/components/HomePage.jsx` (`href="tel:…"`).

**Поменять условия доставки:** в конце `src/data/products.js` задаются `FREE_DELIVERY_FROM` и `DELIVERY_PRICE`. Текст про доставку в окне товара (`ProductModal.jsx`) и в шагах на главной (`HomePage.jsx`) поправьте вручную.

**Поменять тексты главной:** все тексты лежат в начале `src/components/HomePage.jsx` (`STATS`, `STEPS`, `REVIEWS`) и в разметке ниже.

**Поменять интервалы доставки:** массив `TIME_SLOTS` в `src/components/CartPage.jsx`.

## Ограничения

- **Заказы никуда не отправляются.** Они сохраняются только в браузере покупателя (`cvetochki_orders`), магазин их не увидит. Для настоящего магазина нужно отправлять данные формы на сервер, в Telegram-бота или на почту. Это место в коде — функция `createOrder` в `CartContext.jsx`.
- **Оплаты на сайте нет**, подразумевается оплата при получении.
- **Отзывы и рейтинги** — это пример текста, они записаны прямо в коде.
- **Фото** взяты из интернета для примера. Для настоящего магазина замените их своими.

## Частые проблемы

**`npm: command not found`**
Не установлен Node.js. Скачайте его с [nodejs.org](https://nodejs.org/) (версия LTS) и перезапустите терминал.

**Ошибка при `npm install` или `npm run dev` про версию Node**
Обновите Node.js до 20.19 или новее.

**Порт 5173 занят**
Vite сам возьмёт следующий свободный порт (5174, 5175…). Смотрите адрес в терминале.

**Новое фото не появилось**
Проверьте, что имя файла точно совпадает с `id` товара, а расширение — `.jpg`, `.jpeg`, `.png` или `.webp`. Если не помогло, перезапустите `npm run dev`.

**Корзина показывает старые данные**
Очистите `localStorage`: F12 → Application → Local Storage → правый клик → Clear.
